# What's new

[← README](../README.md)

Every release, newest first. Figures in an entry are as measured when it shipped unless it says otherwise; the README's [What it saves](../README.md#what-it-saves) has the current ones. The measurements behind each change, and what was tried and dropped, are in [ROADMAP.md](../ROADMAP.md).

- **0.40 Reports in under a second**: `fix`, `savings` (a bare `context-doctor`), `compact-window`, `cache-ttl`, `cache-misses`, `compactions` and `overhead` read each transcript once per run instead of once per replay, and keep what each replay takes from it (token counts, times, ids; no message text) in `~/.cache/context-doctor`, so the next run reads only what Claude Code appended since, autopilot's replay included (0.6 s with six sessions growing). On the author's 2.7 GB history: `fix` 23.5 s → 5.2 s on a first run and 0.4 s after; `savings` 41.1 s → 17.6 s and 0.5 s. Every figure is unchanged: golden tests compare every report, text and JSON, byte for byte with what the code before printed, with no cache, a cold and a warm one, and after the history grew. `CONTEXT_DOCTOR_NO_CACHE=1` keeps nothing on disk, `CONTEXT_DOCTOR_CACHE_DIR` moves it, `uninstall` removes it ([details](./performance.md#the-transcript-cache)).
- **0.40 A QA pass on 0.39 fixed**: `install` then `uninstall` now gives every config back byte for byte (minified files, inline arrays, CRLF, escapes and number spelling were rewritten before; 9 of 11 configs changed), and removes the skills folders it created. Gemini CLI settings with comments are edited instead of refused. `doctor` warns when an installed skill differs from the shipped one, instead of a ✓. `fix` on a machine with no history says so instead of "nothing left to fix". Also: token counts in profile findings, a negative context window in the status line, the Action pin in the docs, Antigravity in `install --help`, and `GOOGLE_GEMINI_BASE_URL` in the proxy banner ([ROADMAP](../ROADMAP.md#fixed-since-0390)).
- **0.39 `fix`, the cache lifetime, the cache clock, misses in Claude Code's own words, and Antigravity**: `context-doctor fix` is one plan instead of many reports: it replays your last 30 days, ranks every lever by what it would have saved (compact earlier, the prompt cache's lifetime, autopilot where it reaches, MCP tool search when switched off, unused MCP servers and skills in this project), says how each was measured, what it costs in quality and what it writes, and applies a fix only when you answer `y` (or name it with `--apply`); `fix undo` puts back exactly what it changed, and later runs show what each fix saved since. On the author's machine it lists compact earlier at 400k ($1,418 of $2,781, 51%) and a 1-hour cache for the main conversation ($197, 7%). `context-doctor cache-ttl` is that second lever on its own: Claude Code 2.1.243+ lets you pick a 5-minute or 1-hour cache (`promptCacheTtl`, `subagentPromptCacheTtl`); the same content is sent either way, so it is a price-only change, and the replay shows which is cheaper on your own pauses. The plugin gains `/context-doctor:fix`, carries a version, and passes `claude plugin validate --profile directory --strict`; a bare `context-doctor` and `savings` end by pointing at `fix`. An independent QA pass of `fix` was fixed before release: undo leaves values you changed since, edits keep your file's formatting byte for byte, damaged files are refused instead of overwritten, concurrent runs lose nothing, `CLAUDE_CONFIG_DIR` is honoured, and a project, managed or per-model setting that would override a fix is named instead of reported as done. Also on Claude Code 2.1.251+ the status line says until when the prompt cache is warm and what the next turn costs once it is cold (`warm till 14:32 (1h), then +$3.21`). It also logs each cache miss Claude Code diagnoses, and `cache-misses` groups them by cause (tool definitions changed, system prompt changed, idle past the TTL, server-side) with the fix for each, and counts the re-writes that came just too late, naming loops whose interval sits on the cache's lifetime. `install` now wires Antigravity (MCP server and skill). The MCP SDK is 1.32.2, `overhead --mcp` flags servers whose tool list changes between listings, and our own server caps a call's arguments. Fixed from a QA pass before release: running `install` twice then `uninstall` could delete a config you had left empty or `{}`, and the loop check called irregular returns a loop ([ROADMAP](../ROADMAP.md#shipped-in-0390-one-plan-fix-the-cache-lifetime-and-clock-and-antigravity)).
- **0.38 Your limits in their own unit, regressions after upgrades, recall, and a subagent price**: `context-doctor limits` shows each plan window's % (Claude's 5-hour and weekly windows, recorded by the status line; Codex's, from its rollouts), its pace and when it runs out, and what 1M tokens of each kind cost in %, fitted on your own readings and quoted only when the rate is known to ±15%; `savings`, `cache-misses` and `compact-window` then show savings in the limit too. `cache-misses` groups requests by Claude Code version and flags step changes per model (on the author's history, Fable 5.1 in the desktop app wrote 22% of its cache at the 1-hour TTL on 2.1.295, against 100% on 2.1.288). `recall` (an MCP tool and a command) searches the session's own transcript, compacted turns and cleared tool output included, with secrets masked. Before a subagent starts, a hook shows its price at your median for that type, and the Sonnet price where it would run on Opus or Fable; it never blocks (re-run `context-doctor install`, or update the plugin, to add it). `overhead prune` switches off, per project and reversibly, the MCP servers and skills you have not used; `session` and `savings` show the output and reasoning share and price repeated polling; `doctor` names another program on autopilot's port. OpenAI caches now count as warm for up to 24 hours, so autopilot never clears a warm one. An independent QA pass's findings were fixed with tests before the release ([ROADMAP](../ROADMAP.md#shipped-in-0380-limits-regressions-recall-a-subagent-price-and-a-qa-pass)).
- **0.37 Desktop chat apps: a handoff, uploads, compact results, and a security pass**: a chat app's history cannot be edited, so the real cut is a new chat. The `handoff` prompt (one click in Claude Desktop's **+** menu) has the model write a ≤400-token brief plus the blocks that must stay exact and save it with the new `save_handoff` tool, which masks secret-looking strings, keeps the newest 100 under `~/.context-doctor/handoffs`, offers them as `handoff://latest` to attach in the next chat, and reports the per-turn saving (a 52k-token chat drops to ~600). `context-doctor handoff [list|show|latest] [--copy]` reads them. The `ask_file` prompt answers from a big file through `pack_context`; over `--http`, `pack_context` takes ChatGPT uploads (`openai/fileParams`), and ChatGPT gets compact results (54% fewer characters on the sample profile, 51% on an outline of the docs). The standing rules gained the handoff, with the first four ending exactly at character 512. Elicitation forms ask before a handoff or a history prune where the client supports them, and fail closed. An independent QA pass then attacked it; all eleven findings were fixed with tests, among them an SSRF through `textutil` (now `-noload`), DNS rebinding against `--http` (Host and Origin are checked: **behind a tunnel, add `--allowed-hosts <tunnel host>`**), consent failing open, masking gaps, and a symlinked handoffs folder ([handoff](./handoff.md), [ROADMAP](../ROADMAP.md#shipped-in-0370-desktop-chat-apps-and-a-security-pass)).
- **0.36 GitHub Copilot, and a quality test for every lever**: `install` wires GitHub Copilot (the Copilot CLI, the Copilot app and VS Code's agent sessions): the MCP server in `~/.copilot/mcp-config.json`, and a session-start hook that gives each new or resumed session the five standing rules. Copilot hands a transcript only to hooks that cannot add context, so there is no size check there. `doctor` checks both files and warns when VS Code's own `mcp.json` would load the tools a second time. `context-doctor ab` measures whether a lever costs quality: eight small coding tasks, scored by hidden checks, each run with and without the standing rules, autopilot's clearing, `pack_context` or the PreCompact instructions through the Messages API, with pass counts, tokens and cost side by side. It bills your API key, prints the estimate first, sends nothing without `--yes` and never passes `--budget`; the agent's code runs without the key, under a time limit, and is cleaned up after. Built and tested against a local mock API, not yet run on a real key, so no pass rates are claimed yet. Devin was checked again: its CLI keeps history locally, but where and in what format is not documented, so no hook yet ([ROADMAP](../ROADMAP.md#shipped-in-0360-github-copilot-and-the-ab-quality-suite)).
- **0.35 Cache misses, a price before a model switch, and a QA pass fixed**: `context-doctor cache-misses` finds requests that re-wrote the prompt cache while it was still warm (on the author's history: 390 such misses, $1,925 above the cache-read price, 28% of all cache writes; claude-sonnet-5 missed on 10.4% of warm requests, claude-opus-5-5 on 0.11%) and says which model versions miss less; `savings` mentions them when they add up. On Claude Code 2.1.251+ a `PreModelSwitch` hook shows what a `/model` switch will cost before it happens. `pack` no longer reads `.env`, `.npmrc`, private keys or other credential files unless you pass `--include-secrets`, refuses `~/.ssh`-style folders, and survives unreadable files. Fixed from a QA pass: rc values warned as ignored were applied, near-duplicates were counted per pair (781 findings), autopilot's cleared results leaked between conversations reusing tool ids, a malformed config stopped `uninstall` midway, and more ([list](../ROADMAP.md#shipped-in-0350-cache-misses-a-model-switch-price-and-a-qa-pass)).
- **0.34 Native idle compaction, automatic caching, Codex and Cursor fixes**: the cold-resume offer steps aside for Claude Code's own idle compaction (silent after it, still there for the 5-minute caches and sessions under 200k it skips) and uses Claude Code's SessionStart verdict and price on a resumed session; it no longer offers `/compact` on a conversation that was just compacted. `compactions` and `compact-window` tell idle compactions apart. `cache-plan` uses Anthropic's automatic caching (one top-level `cache_control`) for the conversation's moving end, names the requests the API would reject, and prices reads at each model's own rate. Codex on an API key is routed by `autopilot on` through `openai_base_url` in `~/.codex/config.toml` (Codex no longer reads `OPENAI_BASE_URL`); ChatGPT sign-in is left alone, and the proxy answers Codex's WebSocket attempt with 426 so it uses HTTP at once instead of retrying for ~15 s. The proxy gives OpenAI requests without a `prompt_cache_key` a stable one per conversation (models before GPT-5.6), so its turns land on one cache. Cursor: `install` adds `postToolUseFailure` and `sessionStart` hooks beside `postToolUse` (Cursor 3.17+ delivers their context; older versions dropped it), and `doctor` says what your Cursor version does with the guidance. The MCP server's standing rules lead with when to measure, all within the first 512 characters ChatGPT's guide asks for. Measured and dropped: Anthropic's server-side tool-result clearing (7 to 14 of 37 replayed sessions more expensive, against none for autopilot) and capping MCP results in Cursor (1.6% of MCP result tokens). Re-run `context-doctor install` to add the new Claude Code and Cursor hooks.
- **0.33 Easier to start, fewer tokens behind a proxy**: `npx context-doctor` now installs one package and starts in under a second (the MCP SDK is bundled; it took 4.5 to 9 s). A bare `context-doctor` opens on a short "Start here" screen, `--help` is grouped, and unknown flags are errors with a suggestion. With autopilot on, Claude Code keeps MCP tool search on (it turned it off behind a non-Anthropic address, loading every tool definition into every request). `install` no longer duplicates an enabled plugin, `session` profiles the current session, `doctor` exits 1 on failures, `uninstall` removes only what install added, and `savings`, `compact-window` and `overhead` report the same session count and billed baseline. A 1-hour cache marked at the top level of a request is treated as 1 hour. The README is a 185-line front page with the detail in docs/.
- **0.32 A full audit, fixed**: five reviewers read every module against real data; each finding was reproduced, fixed and tested (list in [ROADMAP.md](../ROADMAP.md#fixed-by-a-local-audit-2026-10-13)). The ones that mattered most: `npx context-doctor install` wrote an MCP launcher for a package that does not exist; `uninstall` left Claude Code pointed at a dead proxy port; the optimizer could move one parallel tool result under another's id and drop the note beside them; autopilot could clear output the model had not read; edited histories now respect thinking-block signatures; current prices (Opus 5.5 $4, Sonnet 5.x $2, Haiku 5.5 $0.10) and 1-hour cache writes at 2x; replies counted once and `--days` applied per request. The cold-resume offer follows the cache lifetime a session writes. The README's headline figures were re-measured with it.
- **0.31 Save tokens without losing quality**: a PreCompact hook makes every Claude Code compaction keep the session's changed files, open tasks, your instructions and still-failing tests; `context-doctor compactions` measures re-reads, tool errors and corrections before and after each compaction on your history; `compact-window` now charges the re-reads to every compaction it simulates.
- **0.30 Where the money goes, and a self-healing service**: `context-doctor subagents` compares each subagent's bill with the same work done in the parent session; `cache-plan` places Anthropic `cache_control` breakpoints in an API request and prices them. Fixes from a local audit: the autopilot service now restarts itself onto a newly installed version, `doctor` no longer writes fake hook checks into the activity ledger, and `<synthetic>` placeholder messages no longer hide a session's model.
- **0.29 Python, and where the work goes**: a dependency-free Python package (`python/`) with `pack_documents` for LangChain and LlamaIndex results, `pack_context`, `estimate_tokens` and `profile_messages`, held byte for byte to the TypeScript by parity tests. `context-doctor reads` shows the files read into session after session; `context-doctor tasks` shows cost per commit per project, from your own transcripts.
- **0.28 Wider reach**: `/context-doctor:overhead` and `/context-doctor:pack` in the Claude Code plugin; `pack` reads a folder inside a git repository the way git does, so `.gitignore`'d build output and secrets stay out; `withContextDoctor` wraps Google's `@google/genai` client too; `overhead` measures the fixed start-of-session cost of Codex and Gemini CLI sessions as well as Claude Code's, priced with each provider's cache rules.
- **0.27 Keep waste out**: `pack` and the `pack_context` MCP tool put only the chunks of big files (text, code, PDF, Word, PowerPoint) a question needs into the context, within a budget; `overhead` measures and prices the front matter every request re-reads (system prompt, tools, CLAUDE.md, rules, memory, AGENTS.md, Cursor rules, GEMINI.md). MCP servers sized and their use counted; `overhead split` turns a heavy memory file into a lean one plus a reference file. `withContextDoctor(client)` runs autopilot inside an Anthropic or OpenAI SDK client, for apps with no proxy. Gemini joins: `install` wires Gemini CLI's MCP server and every-prompt hook, `session` and `watch` read its chats, and the proxy and autopilot carry Google's Gemini API. A GitHub Action (and `context-doctor ci`) reports memory-file growth on every pull request and gates on a budget. Re-verified on every surface: 229 tests on macOS, Linux and Windows, plus MCP, OpenAI and Gemini end-to-end smoke runs, now in CI, MCP over stdio and HTTP, the OpenAI proxy, and a live `doctor`.
- **0.26 Checked on every platform, three fixes**: tested end to end in Claude Code (terminal, desktop app, plugin from GitHub), Claude Desktop, Cursor, Codex on GPT-5.5, VS Code, the MCP server on every launch path, and the proxy on OpenAI's APIs. Found and fixed: Cursor's agent never received the hook's guidance (Cursor runs Claude Code's hook where output cannot add context), so `install` now adds a native Cursor hook; Codex blocked the MCP tools behind an approval it never grants in `codex exec`, so the tools are now marked read-only; autopilot skipped Codex's newest tools (`exec`, `wait`) and some of Cursor's. Also: a history imported into Codex no longer reads as "2136% of the window", and the chat-app settings paths are current.
- **0.25 Compact earlier, by itself**: the `/compact` offer at cold resumes was followed 1 time in 33 on the author's machine, so two changes. The hook now also shows you the notice (it went only to the model, which rarely raised it), with the dollar cost of the message you just sent. And `context-doctor compact-window` measures and sets Claude Code's own auto-compact window, which works without anyone acting on advice, in every surface including the desktop app: 50% less input cost at 400k on the author's last 30 days (re-measured in 0.32). `savings` shows it as a third lever.
- **0.24 A full audit, fixed**: the session parser now rebuilds API messages from Claude Code's one-row-per-block transcripts (it had split each reply into several messages, breaking tool pairing in exported conversations and inflating profiles); the proxy forwards every non-conversation endpoint and never re-encodes bodies it does not rewrite (model listing and file uploads failed or were corrupted through it); `report` and the dashboard no longer count compaction as tokens context-doctor saved, and MCP sketches no longer inflate them; `watch` follows plain conversation files; MCP inputs are bounded. 0.23: four dependency vulnerabilities patched, no false `/compact` alarm after compacting, `savings --share`.
- **0.22 Honest about where each lever works, and a new one that works everywhere**: the every-prompt hook now offers `/compact` when you return to a large session after the cache expired (re-measured in 0.32: $2,993 net over 133 days, about $675 a month on the author's history), including in the desktop app. Found and fixed: autopilot cannot reach the desktop app's Code tab, and `doctor` now says so instead of reporting ✓; `savings` counted whole-file history as "last 30 days"; the hook quoted per-message cost at the uncached rate (10x too high). `--version` added.
- **0.21 See it before you install it**: `npx context-doctor savings` replays your own recent sessions through autopilot and shows what it would have saved, against what you were actually billed. Install as a **Claude Code plugin** from inside Claude Code. Ready for the official **MCP Registry** (`io.github.KushalP1/context-doctor`), which every release now publishes to; any MCP client can launch it as `npx -y context-doctor mcp`.
- **0.20.1 Releases that finish themselves**: one tag publishes to npm and creates a GitHub release with the Claude Desktop bundle (signed when a certificate is configured); the editor extension is ready for the VS Code Marketplace and Open VSX.
- **0.20 Autopilot**: stale tool output cleared from every Claude Code request made in a terminal or IDE, only when the prompt cache is cold, so it cannot cost more (re-measured in 0.32: 12.7% less input cost, no session worse); runs as a login service on macOS, Linux and Windows; now also for GPT via OpenAI's Chat Completions and Responses APIs.
- **0.19 Measured Claude tokenizer**: Claude counts about 40% more tokens than the 4-characters rule the estimates used; fixed from the API's own counts, with a per-model check in `accuracy`.
- **0.18** `proxy --token` for putting the proxy on a public URL safely. **0.17** Claude Desktop: a `profile_context` the model can afford to call from chat, `.mcpb` bundle, standing preferences for web and mobile. **0.16** Codex. **0.15** Cursor.
